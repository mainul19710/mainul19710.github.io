# KBKh Science — Telegram Mini App

The Mini App page for the KBKh Science Telegram bot
[@kbkhscienceweb_bot](https://t.me/kbkhscienceweb_bot).

It shows the articles of [kbkhscience.com.bd](https://kbkhscience.com.bd)
inside Telegram — browse by category, search, read full articles and
bookmark — reading everything live from the site's WordPress REST API.

Published with GitHub Pages at https://mainul19710.github.io/
